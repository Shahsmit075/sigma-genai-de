## 2. Business Question Results

When safe SELECT queries are validated, they are executed on Snowflake and converted into user-friendly responses.

### Q1: Total Transactions
* **Question**: "How many transactions do we have in total?"
* **SQL**: 
  ```sql
  SELECT COUNT(*) AS TOTAL_TRANSACTIONS FROM FACT_TRANSACTIONS;
  ```
* **Result**: **50 transactions**
* **Answer**: "There are a total of 50 transactions recorded."

### Q2: Failed Transactions
* **Question**: "How many transactions failed?"
* **SQL**: 
  ```sql
  SELECT COUNT(*) AS FAILED_COUNT FROM FACT_TRANSACTIONS WHERE STATUS = 'FAILED';
  ```
* **Result**: **15 failed transactions**
* **Answer**: "There were 15 transactions that did not go through successfully."

### Q3: Highest Revenue Merchant
* **Question**: "Which merchant had the highest revenue?"
* **SQL**: 
  ```sql
  SELECT m.MERCHANT_NAME,
         SUM(CASE WHEN t.STATUS='COMPLETED' THEN t.AMOUNT ELSE 0 END) AS REVENUE_USD
  FROM FACT_TRANSACTIONS t
  JOIN DIM_MERCHANT m ON t.MERCHANT_ID = m.MERCHANT_ID
  GROUP BY m.MERCHANT_NAME
  ORDER BY REVENUE_USD DESC
  LIMIT 1;
  ```
* **Result**: **Zepto ($5,485.49)**
* **Answer**: "Zepto had the highest revenue among all merchants, generating a total of $5,485.49 from completed transactions."

### Q4: Failure Rate by Payment Method
* **Question**: "What is the failure rate for each payment method?"
* **SQL**: 
  ```sql
  SELECT PAYMENT_METHOD,
         COUNT(*) AS TOTAL_TRANSACTIONS,
         SUM(CASE WHEN STATUS='FAILED' THEN 1 ELSE 0 END) AS FAILED_TRANSACTIONS,
         ROUND(100.0 * SUM(CASE WHEN STATUS='FAILED' THEN 1 ELSE 0 END) / COUNT(*), 2) AS FAILURE_RATE_PCT
  FROM FACT_TRANSACTIONS
  GROUP BY PAYMENT_METHOD
  ORDER BY FAILURE_RATE_PCT DESC;
  ```
* **Results Table**:
  | Payment Method | Total Transactions | Failed Transactions | Failure Rate |
  | :--- | :--- | :--- | :--- |
  | **Debit Card** | 17 | 8 | **47.06%** |
  | **UPI** | 16 | 5 | **31.25%** |
  | **Credit Card** | 17 | 2 | **11.76%** |

### Q5: Total Revenue
* **Question**: "What was the total revenue generated across all merchants?"
* **SQL**: 
  ```sql
  SELECT SUM(AMOUNT) AS TOTAL_REVENUE_USD FROM FACT_TRANSACTIONS WHERE STATUS = 'COMPLETED';
  ```
* **Result**: **$11,120.99**
* **Answer**: "The total revenue generated from all completed transactions across all merchants amounts to $11,120.99."
