### ATHENA helper — use this exactly:

- `start_query_execution()` with `OutputLocation = s3://sigma-phoenix-bucket/athena-results/`
- Poll `get_query_execution()` every 2 seconds until `SUCCEEDED` or `FAILED`
- `get_query_results()` — extract column names from `ResultSetMetadata`
- **CRITICAL**: Athena includes a header row (`Rows[0]`) for `SELECT` queries but **NOT** for
  `SHOW` / `DESCRIBE` / DDL queries. Detect dynamically:

```python
cols = [c["Label"] for c in results["ResultSet"]["ResultSetMetadata"]["ColumnInfo"]]
all_rows = results["ResultSet"]["Rows"]
# Only skip Rows[0] if it actually matches the column names (SELECT header row)
if all_rows and [f.get("VarCharValue", "") for f in all_rows[0]["Data"]] == cols:
    all_rows = all_rows[1:]
data = [[field.get("VarCharValue", "") for field in row["Data"]] for row in all_rows]
return pd.DataFrame(data, columns=cols)
```

**Never use a generic name like `sigma-bucket` or `sigma_db` — these will clash.**
